# Phase 7B — first-responder sequential decision research

**Verdict: CONDITIONAL GO. Algorithm recommendation: no learning yet.**
A plausible sequential information-acquisition task exists, but no measured advantage
over deterministic orchestration has been demonstrated. Training is not ready or
authorized. This phase implements fixture-only research adapters and specifications;
it launches no collection study, incident simulation, agent invocation or enforcement.

## Prior research remains valid

PR #422 addresses deterministic payment authorization. PR #430 prepares the distinct
resource experiment; #433 reports its registered 600 episodes / 18,000 decisions;
#435 audits its physical/control limitations. All five policies violated acceptance
constraints in the four attack families; persistent-static's 240 active ticks exceed
the 64-tick limit and it remains an ineligible diagnostic reference. The existing
control optimum is unresolved, not a universal impossibility theorem. Those outcomes
do not evaluate agent orchestration and are neither erased nor used as training data.

Frozen v6's teacher-relative gain is not evidence of superiority over stronger fixed
comparators or this different action space. Historical v10 gate failures do not become
first-responder successes. No old checkpoint, registry, evidence index or holdout is
modified, re-evaluated or promoted here. See the existing resource-exhaustion and
adaptive-defense research records for their original limitations.
