## Task status values

| Status | Meaning |
|---|---|
| `BLOCKED` | Dependencies not done |
| `READY` | Dependencies done; may be picked up once its phase is authorized |
| `IN_PROGRESS` | Owner and branch set |
| `IN_REVIEW` | PR open |
| `DONE` | Meets [DEFINITION_OF_DONE](DEFINITION_OF_DONE.md) and merged |
| `CUT` | Removed from MVP (moved to backlog with reason) |
